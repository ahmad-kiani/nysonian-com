## Quickstart

Plain HTML and CSS, with no build step.

```bash
git clone https://github.com/ahmad-kiani/nysonian-com.git
cd nysonian-com

npx live-server --port=5501   # dev server on :5501, reloads on save
```

The header and footer are repeated in every page, so a change to either one has to be made in all five HTML files.

## Deployment

Vercel deploys every push to `main`.
